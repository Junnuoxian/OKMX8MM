Demo2 操作清单

电脑端操作：

[ ] A53 Windows测试通过。
[ ] A53能生成存储文件。
[ ] A53能生成MQTT待发文件。
[ ] A53能生成CAN记录。
[ ] A53能生成状态文件。
[ ] A53能生成心跳文件。
[ ] M4采集工程文件齐全。
[ ] M4有RS485和Modbus采集框架。
[ ] 新人能按操作手册跑第一遍。

开发板操作：

[ ] OKMX8MM开发板启动正常。
[ ] A53程序能在开发板上运行。
[ ] M4程序能在开发板上运行。
[ ] 外接采集板能被M4读取。
[ ] SD卡写入稳定。
[ ] 云平台能收到数据。
[ ] CAN工具或矿车能收到数据。
[ ] OTA真实升级流程通过。

操作原则：

先跑电脑端。
再跑开发板A53。
再测SD卡。
再测CAN。
再测云平台。
再启动M4。
最后接采集板和矿车。
