# OKMX8MM
研一项目，用于更新迭代。

## 目录说明

- `OKMX8MM-M4-demo1`：M 核采集程序，当前用于 M4 侧采集验证。
- `OKMX8MM-A53-demo`：A53 侧流程示例，当前先用模拟 M4 数据跑通存储、MQTT 待发、CAN 记录。
- `OKMX8MM-Demo2`：按导师 STM32F407 参考工程整理后的第二版主交付文件夹，集中放 M4、A53、文档、自检和打包脚本。
- `OKMX8MM-Demo3`：STM32F407 外部采集、M4 转发和 A53 存储上传的整合工程。

真实开发板联调前，A53 示例不代表 SD 卡、云平台、CAN 硬件已经实测。
Demo3 的 STM32F407 文件已经接入 HAL 调用，但引脚、收发器和通信参数仍需按实际硬件确认后再烧录。
